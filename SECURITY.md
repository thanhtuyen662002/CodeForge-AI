# Security reporting

Do not open a public issue containing credentials, personal learner data, working sandbox-escape payloads or confidential assessment material. Use GitHub private vulnerability reporting when enabled on this repository. Until a private reporting channel is enabled, contact the repository owner privately through an existing trusted channel; no unverified email address is specified here.

Only test systems you own or are explicitly authorized to test. The red-team document is a design review and a plan for controlled tests, not permission to probe Supabase, Vercel, VinUni, competitors or third-party tenants.

This repository is pre-release. No security certification, completed penetration test or production support SLA is asserted. See docs/SECURITY.md and docs/RED_TEAM.md for the threat model and open release blockers.
