## Agents themselves

| Agent / nguồn | F: scope, free/paid | I: strength, weakness, moat/distribution, switching, AI exposure |
|---|---|---|
| Codex G1 | CLI/IDE/cloud agent, subscription/API, free/paid | Product bundling/models/developer workflow; can supply coaching/review directly. Tool+model dependence for user, no independent skill certification. CodeForge should accept artifacts without deep integration. |
| Cursor G2 | Editor agents/cloud, free/Pro/Teams | IDE daily loop + team configuration/distribution; medium switching via habits/rules; provider/model and usage costs. Can bundle practice cheaply. |
| Claude Code G3 | Agent included Claude Pro/Max | Terminal workflow/model brand; medium habit switching; Anthropic model ecosystem. Documentation/training overlaps CodeForge learning promise. |
| Gemini CLI G4 | CLI/free quota/paid paths | Google distribution and free tier, low monetary switching; model quotas/privacy terms vary. “BYO” must not assume everyone owns paid Claude. |
| Devin/Windsurf G5 | Free/Pro agent product surface | Task delegation/IDE workflow; naming/pricing transition itself signals market drift. Hosting+inference exposure, exact internal costs unknown. |
| Copilot G6 | GitHub/IDE/CLI/cloud agents, free/paid credits | GitHub repo/enterprise distribution, habit/admin lock-in; AI credits variable. Built-in review can eliminate some need for paid drills. |
| Cline G7 | Open source, inference/BYOK, enterprise | Provider choice/community/extension distribution, low software lock-in; user inference bill remains. Strong reference for avoiding vendor-specific evaluator coupling. |

Agents' core loop: task/context→generate/edit/run→review/iterate→merge. CodeForge's proposed loop is *practice a decision on a curated failure*; it must justify extra learner time even when the same agent can explain/generate the exercise free. No model leaderboard is a business moat.

## Competitive decision

INFERENCE: do not compete on number of lessons, languages, agents supported, prompt scores, certificates or low-cost cloud execution. HYPOTHESIS: a small paid practice pack can sell on editorial quality and transfer value; it is easier to kill cheaply than a platform. No defensible claim of uniqueness. Re-evaluate against Kodwai, CodeCrafters, free vendor training and “ask my existing agent” during actual interviews.
